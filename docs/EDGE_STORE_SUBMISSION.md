## 一、商店列表信息（照抄填写）

### 名称
```
螺丝钉下载器
```

### 简短描述（≤ 250 字符）
```
一键采集网页中的图片、视频、音频素材：右键单个保存、批量勾选下载、自动嗅探页面媒体流，配合螺丝钉客户端自动下载并同步到 NAS 素材库。
```

### 详细描述
```
螺丝钉下载器是「螺丝钉-电商智能体矩阵」客户端的配套浏览器扩展，专为电商内容创作者设计，帮助你把浏览网页时看到的素材一键收进自己的素材库。

【核心功能】
• 右键采集：在图片/视频/链接上右键，一键保存到素材库
• 批量采集：自动扫描当前页面全部图片与视频，网格化勾选批量下载
• 媒体嗅探：自动发现网页加载的视频/音频流（含 HLS/m3u8），播放中的视频也能抓
• 快捷键：Alt+点击图片立即采集
• 自动入库：素材经本地客户端桥接自动下载，可同步到 NAS 并触发服务端扫描入库

【使用方式】
1. 安装并运行「螺丝钉」桌面客户端（采集桥接服务默认自动启动）
2. 在网页上右键素材，或点击扩展图标使用批量采集
3. 素材自动下载到客户端配置的目录，可同步 NAS 素材库

【隐私说明】
本扩展仅将素材 URL 发送至本机 127.0.0.1 的客户端桥接服务，不收集、不上传任何用户数据到第三方服务器。
```

## 三、隐私政策（必填）

Edge 要求处理任何用户数据的扩展提供隐私政策 URL。可放到工程 GitHub Pages / 官网，内容模板：

```
螺丝钉下载器 隐私政策

1. 数据收集：本扩展不收集、存储或传输任何个人身份信息。
2. 数据流向：扩展仅将用户主动选择采集的素材 URL（图片/视频地址）
   发送至用户本机 127.0.0.1 运行的「螺丝钉」客户端桥接服务，
   由客户端下载到用户自己配置的目录（本地或用户自有 NAS）。
3. 权限用途：
   - contextMenus：提供右键采集菜单
   - webRequest / <all_urls>：发现页面加载的媒体流地址（嗅探功能）
   - storage：保存桥接地址与端口设置
   - notifications：采集结果提示
4. 第三方共享：不与任何第三方共享数据，无广告、无统计 SDK。
5. 联系我们：<你的邮箱>
```

## 四、提交流程

1. 登录 Partner Center → Microsoft Edge → 创建新扩展
2. 上传 `luosiding-downloader-v1.1.0.zip`
3. 填写上方商店列表信息 + 上传图标/截图 + 隐私政策 URL
4. 「可用性」选 公开 / 全部市场
5. 提交审核（首次约 7 个工作日）

**审核注意（权限说明会被要求填写）**：
- `host_permissions: <all_urls>` → 填写：需要在任意网页上识别并下载用户选择的图片/视频素材，是核心功能必需
- `webRequest` → 填写：用于发现网页加载的媒体流地址（视频嗅探），仅读取请求 URL 与 Content-Type，不修改任何请求
- 访问 `http://127.0.0.1:51233` → 填写：与用户本机运行的配套桌面客户端通信，完成素材下载
