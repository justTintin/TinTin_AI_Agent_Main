## 一、设计系统一致性

### 1.1 色彩体系

| 检查项 | 状态 | 具体问题 | 优先级 | 建议方案 |
|--------|------|----------|--------|----------|
| 主色是否统一 | ⚠️ 部分一致 | 主程序使用 `#6366f1 → #8b5cf6`，素材浏览器接近，浏览器扩展使用 `#3b82f6`，VSR 旧版跟随系统色 | 高 | 所有界面统一使用 Indigo-Violet 品牌渐变；浏览器扩展改为主色 |
| 背景色层级 | ⚠️ 不统一 | 主程序 `#0b0c10`，素材浏览器 `#0b0f19`，扩展 `#1e1f24` | 高 | 统一背景基色 `#0b0c10`，卡片 `#12141d` / `#151722`，输入框 `#171a25` |
| 成功/警告/错误色 | ✅ 基本一致 | 绿 `#34d399`、琥珀 `#fbbf24`、红 `#f87171` | 中 | 保持，扩展中需同步 |
| 文本色阶 | ⚠️ 不统一 | 主程序有 `#f0f1f7` / `#c3c6d2` / `#9ca1b1` / `#73788c`，扩展直接用 `#eee` / `#aaa` | 高 | 扩展采用统一文本色阶 |
| 渐变使用 | ⚠️ 过度使用 | 按钮、标题、进度条多处渐变，容易造成视觉疲劳 | 中 | 主按钮/关键进度保留渐变，普通卡片用纯色 |

### 1.2 字体与排版

| 检查项 | 状态 | 具体问题 | 优先级 | 建议方案 |
|--------|------|----------|--------|----------|
| 中文字体 | ✅ 一致 | 主程序使用 Microsoft YaHei | 低 | 保持，可考虑升级至 PingFang SC / HarmonyOS Sans |
| 英文字体 | ⚠️ 不一致 | 主程序无专门西文字体，素材浏览器用 Outfit | 中 | 统一使用 Inter / Outfit 作为西文主字体 |
| 字号规范 | ⚠️ 不统一 | HTML 中大量 `0.75rem`、`0.82rem`、`13px`、`12px` 混用 | 高 | 建立字号阶梯：`xs=11px`、`sm=12px`、`base=13px`、`md=14px`、`lg=16px`、`xl=18px`、`2xl=21px` |
| 行高 | ⚠️ 不统一 | 部分 `line-height: 1.6`，部分未设置 | 中 | 正文统一 `1.6`，标题 `1.3`，卡片描述 `1.5` |
| 字重 | ⚠️ 过度使用 | 大量 `font-weight: 700` 用于普通标签 | 中 | 标题 700、按钮 600、正文 400/500 |

### 1.3 圆角与间距

| 检查项 | 状态 | 具体问题 | 优先级 | 建议方案 |
|--------|------|----------|--------|----------|
| 圆角规范 | ⚠️ 接近但不统一 | 8px、10px、12px、14px、18px 混用 | 中 | 输入框/按钮 8px、卡片/面板 12px、大弹窗 14px、胶囊 18px |
| 间距体系 | ⚠️ 无规范 | 内边距 8/10/12/14/16/18/20/24px 均有 | 高 | 建立 4px 基线：`4/8/12/16/20/24/32/40` |
| 卡片内边距 | ⚠️ 不一致 | 主程序卡片多为 16px，素材浏览器卡片 12px | 中 | 统一标准卡片 padding 16px，紧凑卡片 12px |

## 十、建议执行顺序

```
Step 1: 建立 Design Library / Design Token
        └─ 颜色 / 字体 / 间距 / 圆角 / 阴影 / 图标

Step 2: 统一基础组件
        └─ Button / Card / Input / Table / Empty / Loading / Toast

Step 3: 治理硬编码样式
        └─ studio/ui/gui_styles.py 作为主样式表
        └─ 素材浏览器 styles.css 与主 token 对齐
        └─ 浏览器扩展新建统一样式

Step 4: 高频页面重设计
        └─ 工作台首页
        └─ 素材浏览器
        └─ 系统设置

Step 5: 全产品走查
        └─ 暗色主题 100% 覆盖
        └─ 浅色主题 100% 覆盖
        └─ 动效与交互一致性
```
