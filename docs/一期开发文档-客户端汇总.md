## 一、产品总纲（商业化 PRD v2.0）

### 1.1 产品定位

面向电商带货商家的 AI 视频创作与运营平台。核心价值：AI 帮你策划→制作→复盘→涨粉，覆盖抖音到全平台。

**商业模式**：软件 License + 素材订阅制。本地负责轻量操作，重算力走私有服务端。

### 1.2 版本体系

```
基础版（付费）      直播切片 + 智能混剪 + 绑定1个抖音号
  └─ 标准版（进阶）  + AI分析 + 文案创作 + 一键成片 + 绑定3个平台账号
       └─ 旗舰版（全功能）+ 数据看板 + 全平台分发 + 数字人 + 工具类 + 绑定无限账号
```

| 版本 | 价格策略 | 可绑定账号数 | 说明 |
|---|---|---|---|
| 基础版 | 低价引流 | 1 个 | 仅抖音 |
| 标准版 | 主力产品 | 3 个 | 抖音 + 任选2平台 |
| 旗舰版 | 高客单价 | 不限 | 全平台（抖音/小红书/B站/快手/视频号/YouTube） |

### 1.3 功能映射（Feature Flag）

| Flag | 版本 | 功能 |
|---|---|---|
| `clip` | 基础 | 直播切片、智能混剪 |
| `copywriting` | 标准 | 知识库、产品资料、产品文案、分镜脚本、飞书选题 |
| `analytics` | 旗舰 | 数据看板、热点追踪、营销检测、视频预测 |
| `distribute` | 旗舰 | 全平台自动发布、格式适配、定时发布 |
| `digital_human` | 旗舰 | 数字人、声音克隆、视频修复、视频去字幕 |

**通用模块（所有版本）**：封面制作、图像抠图、智能分层、视频转文字、OCR、LUT调色、系统设置、素材检索、任务队列。

> 注意：素材管理（本地数据库+CLIP向量索引）已在 v2.0 中移除，改为服务端统一检索。

功能开关映射（`FEATURE_PAGE_MAP`）：`clip`→一键成片/智能混剪/直播切片；`copywriting`→知识库/产品资料/产品文案/分镜脚本/飞书选题；`analytics`→数据看板/热点追踪/营销检测/视频预测；`distribute`→全平台发布/定时发布；`digital_human`→数字人/声音克隆/视频修复/视频去字幕。

### 1.7 技术约束与算力分布

- Python 3.11+ / PySide6 6.6.3 / Qt6；Windows 专用；最低硬件 GTX 1060 6GB + 16GB RAM（本地只跑 ffmpeg+UI）
- 计算服务器：TinTin AI Service Platform（`compute_server_url`）；DeepSeek API 文案生成；Ollama 服务端视觉推理（qwen2.5vl+）；Whisper 转写、VoxCPM 声音克隆、VSR 去字幕均在服务端；ffmpeg + scenedetect 本地处理；Git + Gitea（jckunji.com:3000）
- **服务端负责**：画面描述（Ollama）、语音转写（Whisper）、声音克隆（VoxCPM）、素材检索（CLIP）、去字幕（VSR）、文案生成（DeepSeek）

- 存储：本地磁盘直接扫描 + NAS（SMB/CIFS）挂载扫描；向量检索走服务端，客户端不存索引

## 四、部署与配置（SETUP）

### 4.1 系统要求

| 项目 | 要求 |
|------|------|

显存性能模式（自动检测）：≥16GB 高性能（Ollama并发4/视觉并发4/CLIP批16）；8-16GB 平衡（2/2/8）；<8GB 低能耗（1/1/4）。

### 4.2 启动与外部工具

- 启动：`studio\run_gui_integrated.bat`（自动定位 `python_embeded\pythonw.exe` 启动 `gui_main.py`）
- `ffprobe.exe` 放工程根目录；`ffmpeg.exe` 搜索顺序：`studio/bin/win/` → PATH → 工程根 → `apps/asset-browser/bin/` → `apps/vsr-v1.4.0/backend/ffmpeg/win_x64/`
- Ollama 内置 `studio/bin/win/ollama.exe`（CUDA 12/13 + Vulkan runners 自动选择）；`OLLAMA_KEEP_ALIVE=2m`；视觉模型 `ollama pull qwen2.5vl:7b`

### 4.3 配置文件

> ⚠️ 含凭据的配置文件不入库（本地保留），仓库提供 `.example` 模板（`xxx` 占位）。

**`config.ini`（工程根）**：飞书集成（appid/appsecret/apptoken/tableid/topicfield/scriptfield）+ VoxCPM（modelpath/port）。代码加载的是**工程根目录**的 `config.ini`，不是 `studio/config.ini`。

**`studio/config/ai_config.json`**（AI 服务配置核心）：

| 字段 | 说明 |
|------|------|
| `llm_provider` / `llm_api_url` / `llm_api_key` / `llm_model` | LLM 提供商/地址/密钥/模型 |
| `compute_server_url` | **统一计算节点地址**（ASR/VoxCPM/Ollama/CLIP 共用） |
| `whisper_api_url` / `llm_vision_api_url` / `vox_api_url` / `clip_api_url` / `material_api_url` | 不填则从 `compute_server_url` 派生 |
| `llm_vision_model` | 视觉模型名（如 `qwen2.5vl:7b-16k`） |
| `comfyui_addr` | ComfyUI 独立节点地址 |
| `runninghub_api_key` / `runninghub_base_url` | RunningHub |
| `vox_mode` / `vox_timesteps` / `vox_cfg` | VoxCPM 参数（api/20/2.0） |
| `rustfs_endpoint/access_key/secret_key/bucket` | RustFS/S3 对象存储 |

> 架构说明：AI 推理统一走 `compute_server_url`；客户端只负责 UI 与媒体预处理；各地址可单独覆盖。

**`studio/config/material_index_config.json`**：PostgreSQL（db_host/port/name/user/password）、CLIP（clip_model ViT-B-16 / clip_model_dir / device auto / batch_size）、抽帧 `fps`、标签层级（tag_depth_product=0 / brand=1 / model=2 / category=-1）、NAS（nas_root/user/password）、`index_directories` 映射。注意 `clip_model_dir` 默认硬编码 `D:/Project/...`，换盘需改。

**`studio/config/erp_config.json`**：旺店通 ERP OpenAPI2（base_url/appkey/appsecret/sid），默认沙箱账号。

**`studio/config/theme.json`**：`{"theme": "dark"}`（dark/light/system，程序自动生成，不入库）。

## 六、服务端接口参考（SERVER_API）

> 服务端框架：FastAPI；OpenAPI：`/openapi.json`。⚠️ **客户端不得自行定义接口路径和协议，必须严格对照服务端实际暴露的端点。**

### 6.1 智能混剪

- **`POST /montage/split`**：上传视频镜头分割。参数：`file`（必填）、`threshold`（默认 27，1-100 越小越敏感）、`min_scene_len`（默认 0.5 秒）
- **`POST /material/score_clip`**：镜头评分/分析，入成片任务队列。参数：`file`（必填）、`product_mode`、`analyze_shot`、`frame_at`（0.5）、`product_prompt`（非空时 AI 围绕该产品评分与描述）。响应 `{"task_id","status":"pending"}`；轮询 `GET /tasks/unified/{task_id}`；结果评分在 `result.aesthetic_score.total`（不是 `result.score`），含 clarity/texture/aesthetics/composition/color_quality/figure_quality/subject_prominence 子维度
- **`POST /audio/beatmap`**：音乐卡点，入后台队列。参数：`file`、`count`（>0 时服务端挑 N 段各生成一个视频）、`segment_duration`。结果：`beats`（全曲时间戳，兼容 `beat_times`/`timestamps`/`beat_points`）、`bpm`、`duration`、`clips`（`{start,end,strength}`）

### 6.2 任务队列（通用轮询）

> ✅ **推荐统一使用 `GET /tasks/unified/{task_id}`** 跨队列查询（后台+素材+成片）。原 5 个分散接口兼容保留：`/tasks/{id}`、`/scheduled/tasks/{id}`、`/material/tasks/{id}`、`/vsr/result/{id}`。

- 响应：`{task_id, status: pending|running|completed|failed, result, error}`
- `GET /tasks`（limit/model/status/type/type_prefix 筛选）、`DELETE /tasks/{id}`
- 队列控制：`/tasks/queue/state|pause|resume`、`/tasks/batch_cancel|batch_delete`

### 6.3 素材管理

- `POST /material/search`：CLIP 语义搜索（Body `{query, limit}`，pgvector cosine）
- `POST /material/analyze`（material_id/file_hash/background/file 四选一组合）、`POST /material/score`、`POST /material/ocr`
- 素材任务队列：`/material/tasks*`（列表/查询/取消/队列状态/暂停恢复/批量）
- 其他：`/material/list|schema|distinct|stats|status|config|dirs|scan|serve(Range流式)|delete|batch_score|batch_analyze|enqueue_analysis|logs|logs_list`
- **`POST /material/matting`**：图片抠图，同步返回透明 PNG（`file` 必填；`model`：u2net/u2netp/u2net_human_seg/isnet-general-use）。服务端 rembg `new_session` 缓存 + 信号量限流

### 6.4 Whisper / LLM / VoxCPM

- **`POST /whisper/transcribe`**：`file` + `language`(zh) + `fmt`(srt) + `task_id`
- **`POST /llm/chat/completions`**：统一多模态接口，按 model 自动路由（`{model, messages, max_tokens, temperature, stream}`）；其他：`/llm/models|providers|providers/{key}(/toggle)|templates|stats|records`
- **`POST /voxcpm/tts`**：`{text, prompt_audio(base64/URL), speaker, task_id}`；另有 `/voxcpm/load|unload|health`

### 6.5 VSR 去字幕 / ComfyUI / Ollama / CLIP

- **`POST /vsr/remove`**：`file` + `inpaint_mode`（sttn_det/sttn_auto/lama/propainter）+ `sub_areas`（JSON `[[ymin,ymax,xmin,xmax]]`）。异步：task_id → `/tasks/unified/{id}` → `GET /vsr/download/{filename}`

- **CLIP**：`/clip/encode_image|encode_text|health`

### 6.6 模型调度 / 定时任务 / 系统

- 模型调度：`/models/status|ensure/{service_key}|unload/{service_key}|scan_upgrade|upgrade`
- 定时任务：`/scheduled/tasks`（GET/POST）、`/scheduled/tasks/{task_id}`（GET/PUT/DELETE）、`/scheduled/tasks/queue`、`/scheduled/tasks/evolution/stats|feedback`

**背景与架构**：客户端产品资料库从「直连旺店通 ERP + 本地 JSON 存储」改造为「存储全部迁服务端，客户端经 HTTP 接口操作，以**机器码**（16 位 hex，`SHA256(MAC+主机名+CPU+主板UUID)[:16]`，由 `utils/license.py::get_machine_id()` 生成）作为多租户隔离标识」。

**服务端接口**（`/api/product-library/*`，无需鉴权，中间件白名单放行）：
- 按机器码隔离 CRUD：`GET/POST /clients/{machine_id}/items`、`GET/PUT/DELETE /clients/{machine_id}/items/{item_id}`；新增校验 `brand`/`model` 必填 + `spec_no`（优先）或 `brand+model` 查重（冲突 409）
- 批量 `POST /clients/{machine_id}/upsert`（仓库同步/Excel 导入）
- 客户端专用 `/client/*`：`GET erp-config`（服务端统一下发旺店通凭据，客户端无需本地 `erp_config.json`）、`POST erp-test`（实测 `stock_query` 验证连通）、`GET products`（增量同步 `updated_since` 时间戳 + 分页，响应含 `server_time` 供下次增量）、`GET product/{item_id}`（详情 + `prompt_text` 可直接注入 LLM prompt）
- 增量同步约定：客户端保存 `server_time`（非本地时间，避免时钟偏差）作为下次 `updated_since`

**产品条目字段**：`id`(16位hex)/category/brand/model/goods_no/spec_no(SKU唯一键)/spec_name/barcode/stock_num/available_num/warehouse(「、」分隔)/notes/features(Markdown)/selling_points(Markdown)/created_at/updated_at。

**ERP 移植要点**（原客户端 `WdtClient` 逻辑，服务端复刻）：
- 旺店通 OpenAPI2 签名：参数按 key 字母序排序（跳过 sign），格式 `"{len:02d}-{key}:{len:04d}-{value}"` 分号拼接 + 追加 appsecret → MD5；POST `x-www-form-urlencoded`，`{api_method}.php`，60s 超时，`code=0` 成功
- `stock_query`（分页，响应 `stocks[]`；⚠️ 字段拼写为 `avaliable_num` 非 available）；`goods_query`（时间必填、跨度≤1月，用于品类映射 `class_name`）
- 原客户端链路：产品资料页「从仓库同步」→ `StockSyncWorker` → `WdtClient.fetch_all_stocks()/fetch_goods_class_map()` → `map_stocks_to_kb()` → `ProductLibraryManager.upsert_stocks()/apply_categories()/save()`；消费方：产品文案页（`search/get/to_prompt_text`）、一键成片页（选产品→匹配素材→成片）
