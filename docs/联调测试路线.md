# 业务模块联调测试路线（客户端 ↔ 服务端）

> 用途：指导**服务端**按业务模块逐条链路联调测试。每条链路给出：客户端触发 → 请求（方法/路径/关键字段）→ 服务端处理 → 期望响应/结果 → 服务端自查清单。
> 环境：服务端 `http://192.168.111.28:8000`；视觉模型 `Ollama 192.168.111.28:11435 (qwen2.5vl:7b-16k)`；客户端 `studio/config/ai_config.json` 的 `compute_server_url` 指向服务端。
> 优先级：**1 成片业务 → 2 脚本创作业务 → 3 其它工具链路**。
> 通用约定：异步任务统一轮询 `GET /tasks/unified/{task_id}`（pending→running→completed/failed，result 含 output_url）；任务取消 `DELETE /tasks/{task_id}`；队列 `GET /tasks/queue/state`。

## 一、成片业务（优先级 1）

### 1.1 产品成片（video 模板 + 产品）——主链路

**客户端触发**：产品成片 tab → 选产品 → 选成片模板 → 填模板参数（topic/bgm）→「预览播放」→「开始执行」。

**链路**：
1. `GET /templates?type=video` → 返回 `{templates:[{id,name,type:"video",params:[{name,type,default,label}],effects,render_modes}]}`（ecom_15s / brand_30s）
2. `POST /templates/render`，body `{template_id, params:{topic,bgm}, ratio}` → video 类型返回 `{id, status:"queued"}`（异步）
3. `GET /templates/render/result/{task_id}` 轮询 → `{status:"completed", progress, result:{output_url}}`
4. `GET /templates/render/download/{task_id}` → 下载 mp4（预览播放）
5. `POST /scheduled/tasks`，body `{task_type:"video_montage", title, params:{products:[{brand,model,features,selling_points,category,goods_no}], materials:[], folder, audio, cover, subtitle, ratio, per_dur, count, total_dur, intro, template_id, template_params:{topic,bgm}}}` → 返回 `{id}`
6. 客户端自动跳「成片任务」页轮询 `GET /scheduled/tasks` 或 `GET /tasks/unified/{id}` → `result.output_url` 下载成片

**服务端自查清单**：
- [ ] `/templates?type=video` 返回含 params/effects 的 video 模板
- [ ] `/templates/render` 对 video 返回 JSON 任务（非 PNG）
- [ ] `video_montage` 执行器能消费 `params.products[]`（服务端匹配素材）+ `params.template_id/template_params`（模板引擎），任务完成后 result 含 output_url
- [ ] 缺产品 / 素材匹配不到 / 模板不存在时返回明确的 error

### 1.2 脚本成片（storyboard_montage）

**客户端触发**：脚本成片 tab → 选分镜脚本 → 提交。

**链路**：
1. 脚本来源：本地 JSON `KNOWLEDGE_MEDIA_DIR/<选题>/storyboard/*.json`（后续接服务端 `/api/storyboard/scripts`，见 2.1）
2. `POST /scheduled/tasks`，body `{task_type:"storyboard_montage", title, params:{shots:[{index,duration,scene,copy,materials:[...]}], ratio, ...}}` → `{id}`
3. 轮询 `/tasks/unified/{id}` → result.output_url 下载

**服务端自查清单**：
- [ ] `storyboard_montage` 按 `params.shots[]`（镜号/时长/画面/文案/素材路径）逐镜头成片
- [ ] shots 结构解析与客户端导出一致

### 1.3 卡点成片（/montage/beat）

**客户端触发**：卡点成片 tab → 选音乐 + 选素材（一次上传）→ 设置参数 →「检测卡点/生成」。

**链路**：
1. `POST /montage/beat`（multipart）：`music` + `videos[]`（多次同名字段）+ `variant_count`(≤5) + `time_limit` + `aspect_ratio` + `transition` + `transition_duration` + `min_duration/max_duration` + `count/threshold/min_scene_len/fps/crf` → 返回 `{id, status}`
2. 轮询 `GET /tasks/unified/{task_id}` → `result.variants`（多变体）/ `result.file`
3. 播放/导出：`GET /montage/result/{task_id}/{variant_index}`（逐变体下载）

**服务端自查清单**：
- [ ] 一次上传音乐+多素材；variant_count 上限 5；结果按变体返回
- [ ] 卡点分析（bpm/beats/clips）与 `POST /audio/beatmap` 一致
- [ ] `/montage/result/{task_id}/{variant_index}` 能取到各变体 mp4

### 1.4 智能混剪（split → score_clip → concat）

**客户端触发**：智能混剪页分步执行（素材可从素材检索带入或本地选择）。

**链路**：
1. **镜头分割（服务端接口已具备，2026-08-02 实测）**：`POST /montage/split`（multipart `file`, `threshold`(1-100 默认27), `min_scene_len`(默认0.5)）→ 返回
   ```json
   {"task_id":"...","filename":"a.mp4","total_shots":1,
    "shots":[{"shot_index":1,"filename":"a_shot_001.mp4","start_sec":0.0,"end_sec":3.0,"duration_sec":3.0}],"dedup":null}
   ```
   > 注：客户端当前混剪分割仍走本地 PySceneDetect；服务端 `/montage/split` 已可用，可切换为服务端分割（去掉本地依赖）。
2. 镜头评分/分析：`POST /material/score_clip`（multipart `file`, `product_mode`, `analyze_shot`, `frame_at`）→ `{task_id}` → 轮询 `GET /tasks/unified/{task_id}` → `result.aesthetic_score{total,clarity,texture,aesthetics,composition,color_quality,figure_quality,subject_prominence}` / 画面描述
3. 拼接成片：`POST /montage/concat`（multipart）→ 返回 `{id}` → 轮询 `GET /scheduled/tasks/{id}` → 下载 `GET /montage/concat/result/{id}`。

   **`/montage/concat` 支持两种素材来源（可混合，服务端已实现）**：
   - `files`：客户端选择的**本地素材**（multipart 多文件，按顺序为镜头）
   - `clip_urls`：**素材地址 JSON 数组**，如 `["material://123", "http://.../a.mp4", "/abs/path/b.mp4"]`
     - `material://{id}` = 素材检索地址（服务端按素材库解析到 NAS/本地文件）
     - `http(s)://...` = 远程地址
     - 绝对路径 = 本地已落盘素材路径
     - 图片素材（jpg/png/webp/bmp）自动转静态镜头片段（时长 `image_duration`，默认 3s）
   - 其它 form 字段：`lut`(可选 .cube) / `transition` / `transition_duration` / `width` / `height` / `fps` / `crf` / `preset` / `image_duration`

**服务端自查清单**：
- [ ] `/montage/split` 返回 shots[]（起止时间 + 片段文件），阈值/最短镜头生效
- [ ] `/material/score_clip` 评分在 `result.aesthetic_score.total`（不是 result.score）
- [ ] `/montage/concat` 仅传 `files`（本地）能合成
- [ ] `/montage/concat` 仅传 `clip_urls`（`material://` 素材检索地址 / 本地路径）能合成
- [ ] `/montage/concat` `files` + `clip_urls` **混合**能合成
- [ ] 图片素材经 `clip_urls` 自动转静态片段（image_duration 生效）

### 1.5 封面制作（cover 模板）

**客户端触发**：封面制作 → 封面模板 tab → 选封面模板 → 填参数 → 预览/导出。

**链路**：
1. `GET /templates?type=cover` → 返回 cover 模板（cover_promo/title/quote/gradient/clean，params: title/subtitle/color/bg/fontSize...）
2. `POST /templates/render`，body `{template_id, params:{title,subtitle,color,bg,...}, ratio}` → **cover 类型直接同步返回 PNG**（`content-type: image/png`，1080×1920）

**服务端自查清单**：
- [ ] `/templates/render` 对 cover 返回 image/png（**OpenAPI 目前声明 application/json，与实际不符，建议服务端补声明**）
- [ ] cover 渲染参数（标题/副标题/颜色/背景/字号）正确渲染

### 1.6 MG 动画（/mg/*）

**客户端触发**：MG 动画页 → 选模板 → 填参数 → 生成。

**链路**：
1. `GET /mg/templates` → 模板列表（含参数说明）
2. `POST /mg/generate`，body `{template:"mg_intro", ratio, title, subtitle, color, bg, duration, ...(specs/bars/params 可选)}` → 返回 `{id}`
3. 轮询 `GET /mg/status/{task_id}` → `{id,status,progress,result:{output_url:"/mg/result/{id}"}}`
4. 下载 `GET /mg/result/{task_id}` → video/mp4

**服务端自查清单**：
- [ ] `/mg/generate` 返回 `{id}`（客户端兼容 id/task_id）
- [ ] `/mg/status` 结构如上；`/mg/result` 返回 video/mp4
- [ ] MGRequest 支持 specs/bars/params（mg_benchmark 等模板）
- [ ] 注意：旧任务输出文件被清理后 `/mg/result` 会 404（正常，新任务可用即可）

## 二、脚本创作业务（优先级 2）

### 2.1 分镜脚本服务端存储（CRUD）

**客户端触发**：分镜脚本创作页保存/加载；脚本成片 tab 选择脚本（客户端接入后）。

**链路**：
1. 保存：`POST /api/storyboard/scripts`，body `ScriptIn{topic(必填), ratio, total_duration, shot_count, shots:[{...}], saved_at}` → 返回脚本 id
2. 列表：`GET /api/storyboard/scripts?topic=&page=1&page_size=20` → `{items:[...], total, page, page_size}`
3. 读取：`GET /api/storyboard/scripts/{script_id}`
4. 更新：`PUT /api/storyboard/scripts/{script_id}`（ScriptIn）
5. 删除：`DELETE /api/storyboard/scripts/{script_id}`

**服务端自查清单**：
- [ ] 5 个接口全部可用；列表分页；shots 结构与本地 JSON 一致（topic/ratio/total_duration/shot_count/shots/saved_at）
- [ ] 多端可见（无机器码隔离）；保存/更新/删除后列表同步

### 2.2 脚本 AI 生成（LLM）

**客户端触发**：分镜脚本创作页 → 选题+风格 → 生成分镜。

**链路**：`POST /llm/chat/completions`（或 `/v1/chat/completions`）多模态/文本 → 返回分镜 JSON（shots[]）→ 客户端填表 → 保存（2.1）。

**服务端自查清单**：
- [ ] LLM 输出结构化分镜 JSON（镜号/时长/画面/文案），字段校验通过
- [ ] 与产品文案/知识库上下文可用

### 2.3 脚本 → 成片联动

**链路**：`GET /api/storyboard/scripts`（服务端脚本）→ 脚本成片 tab 选用 → `POST /scheduled/tasks (storyboard_montage)` → 轮询 → 下载。
**自查**：服务端脚本数据能直接驱动成片任务（1.2 复用）。

## 三、其它工具链路（优先级 3）

### 3.1 视频去字幕 / 去水印（/vsr/remove）
**链路**：`POST /vsr/remove`（multipart `file`, `inpaint_mode`, `sub_areas`, `purpose`, `watermark_text`）→ `{task_id}` → 轮询 `GET /tasks/unified/{task_id}` → 下载 `GET /vsr/download/{filename}`。
**自查**：sub_areas 三种格式：空串(智能) / 矩形 `[[ymin,ymax,xmin,xmax]]`（去字幕） / 多边形 `[[[[x1,y1],[x2,y2],[x3,y3],[x4,y4]]]]`（去水印）；去字幕 sttn_det、去水印 sttn_auto；purpose/watermark_text 生效。

### 3.2 视频转文字（/whisper/transcribe）
**链路**：`POST /whisper/transcribe`（multipart `file`, `language`, `fmt`, `task_id`）→ fmt=json 返回 `segments[].words[{word,start,end}]` → 字幕渲染/编辑/导出。
**自查**：srt/json；字级时间戳；中文。

### 3.3 声音克隆（/voxcpm/tts）
**链路**：`POST /voxcpm/tts`，body `{text, prompt_audio(base64/URL), speaker, task_id}` → wav 字节 → 客户端试听/导出。
**自查**：参考音频/文本可克隆；返回音频流。

### 3.4 OCR（/material/ocr）
**链路**：`POST /material/ocr`（`file` 或 `material_id`/`file_hash`）→ `{filename, text, lines:[{text,confidence,box,box_rel}], total}`。
**自查**：box 像素坐标 + box_rel 归一化；选区识别由客户端裁剪后上传。

### 3.5 素材检索（/material/search + /material/list）
**链路**：`POST /material/search`，body `{query, limit, media_type?}` → 候选素材 → `GET /material/thumbnail?material_id=` 缩略图 → 选中后「一键成片」/「智能混剪」带入对应页。
**素材地址直用**：素材检索选中项可转为 `material://{material_id}` 地址，直接作为 `/montage/concat` 的 `clip_urls` 元素（服务端按素材库解析到 NAS/本地文件，免二次上传）——见 1.4。
**自查**：语义检索（CLIP 向量）；分页列表 `/material/list`；缩略图；`material://{id}` 能被 `/montage/concat` 解析。

### 3.6 产品库（/api/product-library/clients/{machine_id}/...）
**链路**：`GET .../grouped`、`.../items`、`.../search`、`.../brands`、`.../categories`、`POST .../sync`、`.../upsert`、`.../apply-categories`、`.../mine`（挖掘）。
**自查**：客户端 product-library manager 读取/同步/挖掘全链路；机器码 machine_id 一致。

### 3.7 素材评分/批量分析（/material/score + /material/analyze + /material/batch_*）
**链路**：`POST /material/score`（material_id/file_hash/product_mode）→ 评分；`POST /material/analyze` → AI 分析；批量 `batch_score/batch_analyze/enqueue_analysis`。
**自查**：评分/分析结果落库并可在 `/material/list` 看到。

### 3.8 视频评价预测 / 营销检测（LLM 视觉）
**链路**：客户端抽帧 → `POST /llm/chat/completions`（多模态 image_url）→ 返回结构化预测/研判 JSON。
**自查**：视觉模型 qwen2.5vl 可用；JSON schema 输出。
