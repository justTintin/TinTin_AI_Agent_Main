# 本地 ComfyUI 集成说明

本目录是工程自带的 **本地 ComfyUI 引擎**，由 `studio` 通过统一客户端
[`studio/utils/comfyui_client.py`](../../studio/utils/comfyui_client.py) 调用。

## 双后端 + 自动回退

studio 里所有对 ComfyUI 的调用（上传、提交 workflow、queue/history、进度 WS、预览/下载）
都走 `comfyui_client`，后端解析策略为：

1. **优先外部**：`AI 设置 → ComfyUI 服务地址`（`ai_config.comfyui_addr`，如局域网那台）
   配置了且能连通 → 用外部。
2. **回退本地**：外部未配置 / 连不上 → 自动用本目录的本地 ComfyUI
   （`python_embeded` 运行，监听 `127.0.0.1:8188`），首次提交任务时按需启动，
   退出 studio 时自动关闭。

> 「被动」操作（系统监控、进度 WS、queue/history 同步）**不会**为了看状态而启动本地；
> 只有「真正提交任务」（上传/提交 workflow）在外部不可用时才会拉起本地。

## 首次使用

1. **装依赖**（用工程内置 python，torch/torchvision 已预装，会自动跳过）：
   - 双击 `安装依赖.bat`，或手动：
     ```
     ..\..\python_embeded\python.exe -m pip install -r requirements.txt
     ```
2. **放模型**：把模型按 ComfyUI 规则放到本目录 `models/` 下
   （`checkpoints/`、`vae/`、`loras/` 等）。源码 clone 不含模型，需自备。
3. **自定义节点**（可选）：数字人/视频修复等 workflow 依赖的自定义节点
   放到 `custom_nodes/`。
4. 测试：双击 `启动-本地ComfyUI.bat`，浏览器打开 `http://127.0.0.1:8188` 验证。

## 端口

本地固定 `127.0.0.1:8188`（与 `comfyui_client.LOCAL_*` 一致）。如需改端口，
改 `studio/utils/comfyui_client.py` 顶部 `LOCAL_PORT`。
