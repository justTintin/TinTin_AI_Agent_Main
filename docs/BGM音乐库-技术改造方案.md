# BGM 音乐库 · 技术改造方案

> 需求编号：#32 ｜ 定位：将「手动选本地 BGM」升级为「内置音乐库选曲」
>
> 关联：`二期开发文档-客户端轻量化.md` §10.2、`需求以及bug修改.md` #32

---

## 一、方案概述

### 1.1 目标

在合成步骤提供内置「音乐库」选曲面板：分类浏览 + 搜索 + 试听 + 一键设为 BGM，选中曲目自动下载/缓存为本地文件后接入现有混音。**现有流程与 `FinalMixWorker` 混音逻辑零改动**。

### 1.2 曲库来源选型（核心决策）

| 方案 | 说明 | 评价 |
|------|------|------|
| **本地自建曲库** | 用户自备音乐按分类/标签入库，本地索引 | ✅ P0 首选，零外部依赖、零合规风险 |
| **免版权在线源** | Pixabay Music / FreePD / Incompetech / 爱给网等 | ✅ P1，合规可商用，部分有 API |
| **扒剪映接口** | 逆向剪映闭源曲库接口 | ⚠️ P2，版权/签名/反爬三重风险，短期不做 |

> **结论**：以**本地自建曲库**打底（P0），叠加**免版权在线源**（P1），**不扒剪映接口**（合规与稳定性风险高，详见 §1.3）。

### 1.3 剪映接口可行性结论（摘要）

- 剪映无官方公开音乐库 API，曲库闭源、需登录态/设备签名
- 扒接口三重风险：**版权合规**（商用高风险）、**签名时效**（`deadline/sign` 易失效、需持续逆向）、**反爬封禁**（设备指纹/风控）
- 故本方案以本地库 + 免版权源为主，剪映逆向仅作 P2 备选且需法务评估

## 二、现状能力盘点

### 2.1 现有 BGM 链路

```
step4_final_view.py
  bgm_input(QLineEdit,只读) + 「选择背景音乐」按钮 → _select_bgm(文件选择器)
  bgm_volume_slider(0~100%，默认15%)
        │
        ▼ bgm_path(本地文件路径) + bgm_volume
FinalMixWorker(tasks, bgm_path, bgm_volume)
  · 校验 BGM 存在 → 预拷贝到本地临时目录（防移动盘 I/O 卡死）
  · BGM 淡入1s/淡出2s；-stream_loop -1 循环
  · 有原声：sidechain 人声闪避 + amix + loudnorm(-16 LUFS)
  · 无原声：BGM volume + fades + loudnorm
  · 卡死看门狗（输出 120s 无增长即终止）
```

### 2.2 关键集成点（零改动接入）

- `FinalMixWorker` 只认**一个本地音频文件路径** `bgm_path`
- 音乐库的产出物 = 选中曲目的**本地文件路径**，写入 `bgm_input` → 走原 `_select_bgm` 之后的既有链路
- `per_video_bgm`（video_montage_page.py）支持按视频维度指定 BGM，可作为进阶能力复用

> 因此改造收敛为：**新增"音乐库面板 + 曲库索引 + 下载缓存"，产出本地路径喂给 `bgm_input`**，混音侧完全复用。

## 四、曲库数据模型

### 4.1 曲目元数据

```python
Track = {
    "id": str,           # 唯一 ID（本地=文件哈希，在线=源ID）
    "title": str,        # 曲名
    "artist": str,       # 作者/来源
    "category": str,     # 分类（见 4.2）
    "tags": [str],       # 标签（卡点/治愈/燃/商务...）
    "duration": float,   # 时长（秒）
    "bpm": int,          # 节拍（可选，卡点场景有用）
    "kind": str,         # "music"(BGM) / "sfx"(音效)
    "source": str,       # local / pixabay / freedpd / aigei / ...
    "remote_url": str,   # 远程音频地址（在线源；本地库为空）
    "local_path": str,   # 本地文件/缓存路径
    "license": str,      # CC0 / CC-BY / 商用授权 / 未知
    "cover_url": str,    # 封面（可选）
}
```

### 4.2 分类体系（对齐剪映）

`推荐 / 热门音乐 / 热门卡点 / 卡点 / 搞笑 / 综艺片段 / 热门综艺 / 影视 / 动画 / 纪录片 / 广告 / 生活 / 游戏 / 科技 / 旅游 / 美食 / 体育 / 时尚 / 科普 / 新闻 / 访谈 / 其他`

- 分类 + 标签双维度：分类单选导航，标签多选筛选
- 本地库入库时可手动指定分类，或按目录约定自动归类

### 4.3 存储选型

| 阶段 | 存储 | 说明 |
|------|------|------|
| P0 | JSON 索引（`data/music_library.json`）+ 文件缓存目录 | 轻量、贴合项目现有 JSON 配置风格 |
| P1+ | SQLite（`data/music_library.db`） | 曲目量大时支持高效检索/分页/去重 |

- 缓存目录：`studio/data/bgm_cache/`（下载曲目落盘，按 id 命名）
- 本地库源目录：用户可配置（自备音乐文件夹），扫描后建立索引（不拷贝原文件）

## 五、音乐库面板设计（`MusicLibraryPanel`）

### 5.1 布局（对齐参考截图）

```
┌──────────────────────────────────────────┐
│  音频库                              [刷新] │
│  [音频] [音效]   🔍 搜索音乐/歌手/内容      │
│ ┌──────────┬───────────────────────────┐ │
│ │ 推荐      │  曲目列表                  │ │
│ │ 热门音乐  │  ▶ 曲名      时长  [试听][选用]│ │
│ │ 热门卡点  │  ▶ ...                    │ │
│ │ 搞笑      │                           │ │
│ │ 影视      │                           │ │
│ │ 生活/...  │                           │ │
│ └──────────┴───────────────────────────┘ │
│  [导入本地音乐]  [在线源设置]              │
└──────────────────────────────────────────┘
```

### 5.2 交互

- **分类导航**：左侧分类树，点击过滤右侧列表
- **搜索**：按 title/artist/tags 模糊匹配
- **试听**：`QMediaPlayer` 播放 `local_path`（在线源未下载时先流式试听 `preview_url`），支持暂停/停止（复用现有音频播放三态逻辑）
- **选用**：
  - 本地库 → 直接返回 `local_path`
  - 在线源 → 先下载到缓存 → 返回缓存路径
  - 写入 `bgm_input` 并关闭面板
- **导入本地音乐**：文件选择器（多选 mp3/wav/m4a）→ 探测时长 → 写入索引
- **音效 Tab**：`kind=sfx`，供后续音效功能复用（本期先占位）

### 5.3 入口接入

- `step4_final_view.py` BGM 输入行新增「🎵 从音乐库选择」按钮 → 打开 `MusicLibraryPanel`
- 保留现有「选择背景音乐」（本地文件选择器）作为兜底，两种方式并存
- 文案驱动新流程（#31）的 SD-4 合成视图同样接入该面板

## 六、下载缓存与在线源

### 6.1 缓存策略

- 选中在线曲目 → 检查 `bgm_cache/{id}` 是否已存在 → 命中直接用，未命中则下载
- 下载用流式写入 + SHA256 校验（在线源提供时）；失败可重试
- 缓存淘汰：LRU（可选，超过阈值清理最久未用）

### 6.2 在线源适配（P1）

以**源适配器**模式封装，便于扩展：

```python
class MusicSourceBase:
    def search(self, keyword, category) -> list[Track]: ...
    def resolve_url(self, track) -> str: ...   # 返回可下载直链

class PixabaySource(MusicSourceBase): ...   # 有官方 API（需 key）
class FreePDSource(MusicSourceBase): ...    # 免版权，静态列表
class LocalSource(MusicSourceBase): ...     # 本地库（P0）
```

- 在线源建议**服务端代理转发**（规避客户端直连风控/隐藏 API key）：服务端新增 `/music/*` 代理端点，客户端经 `compute_server_url` 访问
- 版权标注：每曲目记录 `license`，UI 对非商用授权给出提示

## 九、分期实施

**P0 · 本地曲库（零外部依赖，先落地）**
- `music_library.py`：JSON 索引 + 本地扫描入库 + 时长探测
- `music_library_panel.py`：分类/搜索/试听/选用
- `step4_final_view.py` 接入「从音乐库选择」
- 验收：自备音乐入库 → 分类/搜索/试听 → 一键设为 BGM → 正常混音出片

**P1 · 免版权在线源**
- 源适配器框架 + Pixabay/FreePD 等接入
- 下载缓存 + SHA256 校验 + LRU
- （可选）服务端 `/music/*` 代理

**P2 · 剪映接口评估（仅合规允许时）**
- 法务/合规评估 → 抓包 PoC → 稳定性与风险评估 → 决策是否接入

## 十、风险与对策

| 风险 | 对策 |
|------|------|
| 扒剪映接口的版权/封禁风险 | 不主动扒；走免版权源或本地库 |
| 在线源接口变更/失效 | 源适配器隔离 + 多源冗余 + 本地缓存兜底 |
| 大文件下载慢/失败 | 流式下载 + 重试 + 试听用 preview 不等整曲 |
| 非商用音乐误用于商用视频 | `license` 字段标注 + UI 提示 |
| 曲目量大检索慢 | P1 升级 SQLite + 分页 |
| 误改现有混音 | 面板仅产出本地路径喂 `bgm_input`，`FinalMixWorker` 零改动 |
