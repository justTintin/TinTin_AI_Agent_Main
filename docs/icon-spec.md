# 丁大怪-电商智能体矩阵 · 图标系统设计规范

## 风格定义
- **风格**：线性图标（Stroke），圆角端点
- **网格**：24×24px 基准
- **线宽**：2px
- **颜色**：继承主题色（`var(--text-secondary)`），激活态（`var(--accent)`）
